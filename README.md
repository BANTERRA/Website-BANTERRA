# Website-BANTERRA
BANTERRA adalah pupuk organik granul yang memanfaatkan limbah batang semu pisang sebagai salah satu komponen formulasi. Produk ini dikembangkan untuk menjawab dua persoalan sekaligus: limbah gedebog pisang yang belum dimanfaatkan optimal serta kebutuhan petani akan pupuk organik yang lebih praktis ditakar, disimpan.
